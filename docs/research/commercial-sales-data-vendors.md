## 2. 서비스별 핵심 메모

### 오픈업 (운영: 주식회사 핀다)
- 매출 수치 옆 고정 문구: "매출값은 **오픈업 AI가 다양한 기반정보를 학습하여 계산한 추정매출**로, 매장·건물·상권·지역과 관련된 **어떠한 사실도 증명하지 않으며 이러한 사실 증명에 활용할 수 없습니다**" → 절대값보다 **경향 분석 참고용**으로 쓰라고 명시.
- 학습 데이터 출처에 **국세청·시중 카드사·통신사·행안부·국토부**가 모두 열거되지만, 결과물은 카드 결제액 집계가 아니라 **AI 추정값**. 현금·지역화폐·온라인 플랫폼·일부 배달대행은 반영 비중 낮음(오차 요인으로 공식 인정).
- 아웃라이어(예측값 과대/과소)는 표시하지 않도록 설계.
- 사업주 신청 시 **자기 매장 추정매출 비공개 처리** 가능(약관 제4조의2). 비공개 매장은 서비스 내 모든 계산에서 제외 → 상권 집계값에도 영향.
- 2025-09-25부로 ‘내 매장 보고서 – **실매출 조회**’ 종료. 현재 일반 이용자에게 실매출 기능 없음.
- 데이터 출처 표기 의무가 약관에 구체적으로 규정된 유일한 서비스(서비스명 + URL + 참조일자).
- 매장 단위 **과거 시계열은 정책적으로 미공개**, 시계열은 상권 단위만.

### 나이스비즈맵
- 지표 구조상 **실결제 집계 지표**(점포당 평균 매출, 중위/상하위 20% 매출, 이용 건수, 결제 단가, POS 기반 메뉴·가격대)와 **추정 지표**(프리미엄보고서 ‘추정 매출액·수익성’, 사업성 종합등급)가 **명확히 분리**되어 있음.
- 업종 체계 426개 소분류, 한국표준산업분류(KSIC) 연계. 결제가 발생하는 가맹점이 있으면 모든 업종 분석 가능.
- 무료 종합보고서 **일 5회** 제한. 프리미엄보고서 **55,000원/건**, PDF 출력 가능.
- 기업 제휴 상품에서 **API/파일(XLSX·CSV) 제공**을 공식적으로 명시 → 3사 중 유일하게 합법적 데이터 취득 경로가 명문화되어 있음.
- 약관 제20조 라목·자목이 넓어, **회사 사전 승낙 없는 정보 재사용·영리 사용이 정면 금지**. 크롤링을 이름으로 금지하진 않지만 재사용은 확실히 금지.

### NICE지니데이타
- 나이스비즈맵의 **운영사**이며, 동시에 B2B 데이터·컨설팅 본체. 개인 대상 상권분석 서비스는 나이스비즈맵으로 연결, 구독형 리포트는 **NICE MARKET INFO**(nicemarketinfo.co.kr), 가명결합은 ‘디지털 라이프 데이터 댐’.
- 상업 빅데이터 500여 종, 전국 320만 상가정보, 연간 50여 융합 분석 프로젝트 수행이라 자체 소개.
- NICE그룹 내 **카드결제VAN·POS솔루션** 보유가 실결제 데이터 접근의 구조적 근거.
- **요금·갱신주기·이용약관·공개 API 모두 웹에서 확인되지 않음** — 전부 문의/계약 기반.

## 3. 실무상 유의점 (본 프로젝트 관점)

1. **오픈업 수치는 법적·회계적 근거로 사용 불가**가 약관·화면에 명문화되어 있다. 부동산 가치 산정 근거로 인용하려면 "추정매출(오픈업 AI)" 라벨과 출처 표기가 필수.
2. **3사 모두 크롤링·자동수집으로 얻은 데이터의 재사용은 약관 위반**이다(오픈업 제7·8조, 나이스비즈맵 제20조). 오픈업은 robots.txt로도 대부분 경로를 비허용.
3. 합법적 대량 취득 경로가 문서로 확인되는 곳은 **나이스비즈맵 Enterprise(API/XLSX/CSV, 가격 문의)** 뿐이다. 오픈업은 오픈업 프로 또는 사전 동의 계약, NICE지니데이타는 B2B 계약/데이터 바우처.
4. 지표 비교 시 **나이스비즈맵의 ‘점포당 평균 매출/결제 단가’(실결제 집계)** 와 **오픈업의 ‘추정매출’(모델 산출)** 을 동일 축에 놓고 비교하면 안 된다.
5. 두 서비스 모두 **폐업·신규 점포 반영 지연**이 있다(오픈업 2~3개월 공식 인정, 나이스비즈맵은 월 단위 정기 갱신).
