# 지역별 유동인구·생활인구·보행량 공공데이터 조사

- 조사 기준일: **2026-09-29 KST**
- 대상: 서울, 부산, 대구, 인천, 광주, 대전, 울산, 세종, 경기, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주
- 목적: 부동산 매물 좌표 주변(도보권·반경권) 입지분석에 실제 사용할 수 있는지 평가
- 원칙: 검색결과가 아니라 `data.go.kr` 또는 지자체 포털의 상세 페이지를 우선 확인했다. 상세 페이지에서 확인하지 못한 내용은 **미확인**으로 표시했다.

## 1. 결론

### 즉시 도입 우선순위

1. **서울**: 집계구/행정동 × 시간대 생활인구가 계속 공급되고, 최근 2개월은 Sheet/Open API로 제공된다. 집계구 경계와 조인하면 좌표 주변 분석에 가장 적합하다.[14]
2. **경기**: 전 도 행정동 × 시간대 × 내외국인 × 성·연령 집계가 자동 갱신되는 파일로 확인된다. 좌표를 행정동에 귀속시키는 방식의 전국 서비스 운영에 적합하다.[12]
3. **부산**: 전 시 행정동 단위 월별 일평균 생활인구(주거·직장·방문)가 2019-01~2025-12 범위로 확인된다. 부산진구에는 격자 경계와 1분 단위 유동인구라는 더 세밀한 보조자료가 있다.[29][17]
4. **울산 울주군**: 반(班)·16방위 공간정보 SHP에 성·연령 및 00~23시 유동인구 필드가 있어 공간 해상도는 높다. 다만 2022년 일회성 자료다.[34]
5. **강원 동해시**: 100m 격자 × 1시간의 보행자·비보행자 지수 API라 공간 분석에는 좋지만 데이터 기간이 2019~2020으로 오래되었다.[7]

### 제한 도입

- **대전 유성구, 경북 포항시, 경남 김해시** 자료는 행정동 분석에 쓸 수 있으나 지역 범위 또는 최신성 제약이 크다.[33][41][42]
- **제주 읍면동 API**도 행정동급 분석 후보지만 상세 페이지에 실제 제공기간이 표시되지 않는다.[9]
- **제주 PNU 자료**는 필지 수준으로 매우 세밀하지만 2015~2016 관광객 자료여서 현재 상권의 절대값으로 사용하면 안 된다.[43]
- **인천**에서 확인된 자료는 시 전체 연령별 주·야간 인구 15행뿐이며 좌표 분석용 공간키가 없다.[31]

### 공식 개방 공백

- **광주·세종·충북**은 공식 포털 또는 분석 화면까지만 확인했고, 좌표 분석에 필요한 공간키·기간·다운로드/API 상세는 확인하지 못했다.[32][35][37]
- **충남·전북·전남**도 같은 상태로, 공개 상세 데이터의 운영 적재 가능성을 확인하지 못했다.[38][39][40]
- **대구 수성구 CCTV 유동인구**는 검색 색인에는 남아 있으나 공식 상세 URL이 현재 “페이지를 찾을 수 없음”으로 반환되어 운영 데이터로 채택할 수 없다.[30]

## 2. 평가 기준

| 등급 | 공간 해상도 | 매물 좌표 활용 판단 |
|---|---|---|
| A | 점 좌표, 필지/PNU, 100~300m 격자, 집계구 | 300m·500m·1km 버퍼 집계 가능. 좌표 주변 분석에 직접 사용 |
| B | 행정동/읍면동 또는 소규모 상권 코드 | point-in-polygon으로 귀속 가능하나 동일 동 안의 미시적 차이는 설명 못함 |
| C | 시군구·광역시 전체, 특정 시설 몇 곳, 시각화 전용 | 지역 비교나 보조지표로만 사용 |
| D | 상세 데이터 미확인, 삭제, 기간 불명 | 운영 파이프라인에 사용하지 않음 |

최신성은 **실제 관측기간**을 기준으로 평가했다. 포털의 “수정일”이 최근이어도 원자료가 과거이면 최신으로 보지 않았다.

## 4. 전국 보완재

행정안전부 생활인구 파일은 89개 인구감소지역의 2024년 3분기 생활인구(인구수·성별·연령별)와 체류 특성(이동패턴·소비형태)을 제공하고 갱신주기를 분기로 명시한다.[15] 강원·충북·충남·전북·전남·경북·경남의 일부 군 지역을 넓게 보완할 수 있지만, 매물 반경 분석용 격자/좌표 데이터가 아니라 지역 단위 정책통계이므로 **C 등급 보조지표**로만 사용한다.

공식 상세: [행정안전부_생활인구](https://www.data.go.kr/data/15130539/fileData.do)

## 5. 제품 적용 권고

### 데이터 모델

최소 공통 스키마를 다음과 같이 분리한다.

- `source_id`, `source_url`, `provider`, `license`
- `observed_at` 또는 `period_start`/`period_end`, `published_at`, `retrieved_at`
- `spatial_type`: `point | pnu | grid | census_block | admin_dong | sigungu`
- `spatial_id`, `geometry`, `crs`, `resolution_m`
- `population_type`: `living | floating | resident | workplace | visitor | pedestrian_index`
- `value`, `unit`, `gender`, `age_band`, `hour`, `weekday`
- `coverage_area`, `is_sample`, `is_index`, `freshness_grade`

### 좌표 주변 계산

- A급: 매물 좌표 기준 300m·500m·1km 버퍼와 격자/집계구/필지 geometry를 교차하고 면적가중 합계를 계산한다.
- B급: 좌표를 행정동 폴리곤에 귀속하고, “매물 반경 유동인구”가 아니라 **“소속 행정동 생활인구”**로 표시한다.
- 지수형(동해): 인구 “명”으로 변환하지 말고 동일 도시 내 백분위/등급으로만 노출한다.
- 오래된 A급(제주 PNU, 동해 100m): 현재 절대값이 아니라 역사적 보행·관광 중심성 피처로만 사용한다.

### 운영 게이트

1. 원자료의 실제 최종 관측일이 12개월 이내인지 검사한다.
2. 수정일과 관측일을 분리 저장한다.
3. CRS와 공간키 정의서를 확인하지 못한 데이터는 적재를 차단한다.
4. 이동통신사 추정치는 통신사·시장점유율 보정 여부와 산정 정의를 메타데이터로 노출한다.
5. API 명세만 있고 실제 기간이 없는 제주·포항은 샘플 호출로 `min/max 관측일`, null률, 중복키를 검증한 뒤 운영 승인한다.
6. 삭제된 대구 API와 시각화 전용 포털은 자동수집 대상에서 제외한다.

## 6. 한계와 미확인 사항

- 로그인/활용신청이 필요한 API는 서비스키 없이 실제 응답값을 호출하지 않았다. 따라서 제주·포항 API의 실제 최신 관측일은 미확인이다.
- 부산진구 격자의 실제 크기·CRS, 강원 융합데이터의 정확한 격자 정의는 다운로드 원본/정의서 추가 확인이 필요하다.
- 광주·충북·충남·전북·전남은 포털 또는 시각화 존재까지는 확인했으나, 공개 다운로드/API 상세의 공간키와 최신성을 확인하지 못했다.
- 대구 수성구 데이터는 검색 색인의 설명과 달리 공식 상세 페이지가 현재 삭제 상태였다.
