### 2.3 BASA (basadata.com) — 검색 결과의 통념을 정정해야 함

**사실 정정**: BASA는 **신용보증기금(KODIT, Korea Credit Guarantee Fund)**이 운영한다. 서울시 상권분석의 보정비율 제공기관인 **서울신용보증재단과는 전혀 다른 기관**이다. (컨텍스트의 "신용보증기금 관련 서비스로 보임"은 맞으나, 서울신용보증재단과 혼동해서는 안 된다.)

- 조사 시점에 `www.basadata.com`(210.96.165.7)은 **직접 접속 불가**: browser CDP 타임아웃, curl HTTPS 40초 타임아웃, TLS 핸드셰이크 미완료. HTTP(80)는 302를 반환하지만 Location 헤더가 `https://www.basadata.combo/tradeAnalysis.do`로 **깨져 있다**(서버 리다이렉트 설정 오류, Server 헤더는 `-_-`). 국내 IP 한정 접근 제어 또는 서버 측 문제로 추정.
- Wayback Machine에 `/bo/tradeAnalysis.do` 및 `/main/hlpInfo.do` 스냅샷이 **존재하지 않음**(SPA/로그인 게이트 추정). 따라서 **상권분석 화면의 매출 지표명·출처·공간단위·갱신주기는 공식 근거로 확인할 수 없었다.**
- 공식 근거로 확인된 것 (KODIT 홈페이지, Wayback 2026-03-16 / 2026-01-14 스냅샷):
  - BASA = Business Analytics System on AI. 신용보증기금이 1976년부터 축적한 기업DB + 신용평가 노하우에 빅데이터·AI를 결합한 기업 데이터 서비스.
  - 3개 서비스: AI 경영진단 / 기업정보조회(약 140만개 기업) / 기업통계. "**일부 서비스는 유료로 제공**".
  - 소상공인 관련: "중소·중견기업만 대상이냐고요? 아닙니다! **소상공인은 상권분석을 통한 영업 솔루션까지** 제시해 드립니다", "소상공인을 위한 상권분석 정보 — 우리동네 영업환경, 잠재고객, 경쟁강도를 알기 쉽게 분석" (basadata.com 첫화면, Wayback 2026-06-11).
  - 이용 유의사항: 신용정보법 준수 / 기준일 이후 변동 미반영 / **조달청 등 공공기관 입찰 적격심사 활용 불가** / 결과는 경영진단 참고용·거래처 신용도 조회용으로만 제공되며 **타 기관에는 활용할 수 없음**.
  - 이용 조건: 회원가입 시 공동인증서 또는 금융인증서 필요.
- **판단**: BASA는 본질적으로 기업신용·경영진단 서비스이며, 상권분석은 소상공인 대상 부가 기능이다. 공개 API/벌크 다운로드 제공 근거는 발견되지 않았고, 이용약관상 결과물의 타 기관 활용이 금지되어 **파이프라인 소스로는 부적합**으로 보인다(단, 화면 미확인이므로 단정하지 않음).

### 2.4 공공데이터포털 소상공인시장진흥공단_상가(상권)정보 API — 매출 데이터 아님

가장 흔한 오해를 명확히 해야 한다. 이 API의 이름에 "상권"이 들어가지만 **매출 지표를 일절 제공하지 않는다.**

- 공식 설명: "데이터 출처: 국세청/카드사", "주요 제공항목: **상가업소번호, 상호명, 주소, 상권업종명, 표준산업분류명, 경도, 위도 등**". 즉 국세청·카드사 데이터는 *업소의 존재와 업종 판별*에 쓰였을 뿐, 결제액은 노출되지 않는다.
- Base URL: `apis.data.go.kr/B553077/api/open/sdsc2`, REST, JSON+XML.
- 확인된 엔드포인트 19개 — `storeListInRadius`, `storeListInRectangle`, `storeListInPolygon`, `storeListInAdmi`(행정동), `storeListInPnu`, `storeListInBuilding`, `storeListInUpjong`, `storeListByDate`, `storeOne`, `storeZoneInRadius`, `storeZoneOne`, `largeUpjongList` / `middleUpjongList` / `smallUpjongList`, `reqStoreModify` 등. **매출 관련 엔드포인트 0개.**
- 업종분류: 표준산업분류(10차) 기반, 대분류 10 / 중분류 75 / 소분류 247. 업종코드 자릿수 2/4/6.
- 트래픽: 개발계정 10,000, 운영계정은 활용사례 등록 시 증액 신청 가능. 심의는 개발·운영 모두 자동승인.
- 라이선스: 무료, **이용허락범위 제한 없음**. 등록일 2015-12-22, 수정일 2026-08-14, 활용신청 14,893건.

## 3. 실무 결론

1. **기계판독 가능한 매출 데이터는 사실상 서울시 하나뿐이다.** 서울 열린데이터광장의 `VwsmTrdarSelngQq` / `VwsmAdstrdSelngW` 계열이 유일하게 (a) Open API + CSV/SHP, (b) 공공누리 1유형(상업적 이용 가능), (c) 분기 시계열, (d) 산식 공개를 모두 충족한다. 단 서울 한정.
2. **전국 단위 매출은 API로 못 가져온다.** 소상공인365가 전국 월단위 매출을 보유하지만 화면 조회만 가능하고, 공개 API는 업소 위치·업종에 한정된다. 전국 매출이 필요하면 별도 협의·제공신청 경로를 검토해야 한다.
3. **모든 지표는 "추정매출"이며 실제 카드 결제액이 아니다.** 서울시는 `카드결제금액 ÷ 보정비율`임을 명시하므로, 카드 침투율 가정이 틀리면 오차가 그대로 전파된다. 특히 현금·간편결제 비중이 높은 업종, 표본이 얇은 소규모 상권에서 신뢰도가 낮다. 단일 카드사(신한카드) 표본에 의존한다는 점도 대표성 한계다.
4. **라이선스 리스크는 소상공인365가 가장 크다.** "기준 데이터" 페이지의 비상업·개인용도 한정 문구와 저작권정책의 자유이용 허가가 상충한다. 상업 서비스에 투입하기 전 소진공 AI빅데이터실(042-363-7578) 또는 webmaster@semas.or.kr에 서면 확인을 받아야 한다.
5. **시계열 설계 시 단절을 반영해야 한다.** 서울시는 2026-07-03부터 2021년 이전 매출 데이터를 내렸고, 2024년부터 집계 공간단위가 표준단위구역으로 바뀌었다. 2021년 이전과 이후, 2024년 전후를 연속 시계열로 취급하면 안 된다.
6. **BASA는 데이터 소스 후보에서 제외 권고.** 접속 불가 + API 부재 + 약관상 타 기관 활용 금지. 필요하면 국내망에서 재확인.

## 4. 확인되지 않은 항목 (명시적 기록)

- BASA 상권분석 화면의 매출 지표 명칭, 정확한 데이터 출처(카드사명), 공간단위, 기간·갱신주기 — 사이트 접속 불가 및 아카이브 스냅샷 부재.
- BASA의 공개 API/다운로드 제공 여부 — 제공한다는 근거도, 제공하지 않는다는 명시적 근거도 공식 페이지에서 확인 못 함.
- 소상공인365 매출 데이터의 카드사명(어느 카드사인지) — "카드사"로만 표기.
- 소상공인365 매출 지표의 보정·추정 방법론 — 산식 공개 없음(서울시와 달리).
- 서울시 추정매출의 보정비율 실제 수치 및 산정 방법 — 산식 구조만 공개, 비율값은 비공개.
