# 무료 공공 데이터 레이어

조사 기준일 2026-09-29 KST. 각 항목은 공식 상세 페이지를 직접 열어 확인했다.
정보가 확인되지 않은 항목은 `확인되지 않음`으로 남긴다.

## 이 문서의 전제

국내에는 **실제 카드 결제액 원자료를 전국 단위로 무료 공개하는 서비스가 없다.**
무료로 얻을 수 있는 것은 셋 중 하나다.

1. 보정된 추정매출 (서울시 골목상권)
2. 구간으로 마스킹된 결제 지표 (서울시 실시간 상권현황)
3. 지역화폐 결제분만 담긴 소비 (한국조폐공사)

따라서 화면에는 각 숫자를 만들어낸 방법대로 이름을 붙이고, 전체 카드매출이라고
표현하지 않는다.

## 도입한 레이어

정의 위치: `src/lib/public-data-layers.ts` (`PUBLIC_DATA_LAYERS`).
레이어를 추가할 때는 출처·지표의미·공간단위·산정방식·한계·라이선스·공식URL을 모두 채운다.
하나라도 비면 계약 테스트가 실패한다.

### 전국 적용

**거주인구 추정** — 통계청 SGIS
행정구역 평균 인구밀도를 반경 500m 원 면적에 단순 환산한다.
동네 안에서 사람이 몰린 곳과 빈 곳을 구분하지 못한다. 지표의미 `estimated`.

**시설 밀집 참고도** — 카카오 로컬 API
장소 좌표에 시각화용 가중치를 부여한 그림이다. 사람 수를 센 값이 아니다.
지표의미 `proxy`. 이 이름 외에 `유동인구 히트맵`으로 부르지 않는다.

**주변 점포·업종 구성** — 소상공인시장진흥공단
https://www.data.go.kr/data/15012005/openapi.do
반경 내 점포를 업종별로 집계한다. 조회 상한이 있어 전체 점포 수가 아니다.
현행 공식 명세에 매출·유동인구 항목은 없다.
조회 상한으로 절단된 집계이므로 지표의미는 `sample_observed`다.

**지역화폐 업종별 소비** — 한국조폐공사
https://www.data.go.kr/data/15149767/openapi.do
시군구·읍면동 × 업종 결제금액과 결제건수. 이용허락범위 제한 없음.
지역화폐 결제분만 포함되므로 지표의미 `local_currency`.
`전체 카드매출`이나 `상권 총매출`로 표기하면 안 된다.

### 서울 전용

**서울 주요 상권 실시간 결제 동향** — 서울특별시 (신한카드 제공)
https://data.seoul.go.kr/dataList/OA-22385/A/1/datasetView.do
공공누리 1유형이라 출처표시하면 상업적 이용이 가능하다. 10분 갱신.

한계 세 가지를 반드시 함께 표시한다.

1. **결제금액은 정확한 금액이 아니라 5만원 단위 구간(MIN/MAX)으로만 공개된다.**
   결제건수만 정수다. 구간을 평균 내어 단일 값으로 만들지 않는다.
2. 서울 주요 장소 82곳만 제공된다. 임의의 매물 좌표를 커버하지 않는다.
3. 과거 이력이 적재되지 않는다. 시계열이 필요하면 직접 수집해 쌓아야 한다.

실측 응답 구조 (2026-09-29 확인):

```
AREA_CMRCL_LVL: "한산한"          # 4단계 등급
AREA_SH_PAYMENT_CNT: "130"        # 결제건수, 정수
AREA_SH_PAYMENT_AMT_MIN: 1000000  # 구간 하한
AREA_SH_PAYMENT_AMT_MAX: 1100000  # 구간 상한
CMRCL_RSB[]: 업종 대·중분류별 동일 지표 + RSB_MCT_CNT(가맹점수)
CMRCL_TIME: "20260929 0850"
```

**서울 생활인구 추계**, **서울 상권 추정매출**
추정매출 산식은 `신한카드 결제금액 ÷ 서울신용보증재단 보정비율`이다.
단일 카드사 표본을 보정한 추정치이며, 2021년 이전 값과 2024년 이후 공간단위를
이어 붙일 수 없다.

## 정직성 방어선

독립 감사에서 지적된 지점과 대응이다. 모두 계약 테스트로 고정했다.

**지역 판별은 문자열 선두에만 앵커한다.**
`경기도 부천시 부산로 12`, `전라남도 목포시 제주로 3` 같은 도로명이 전국에 실존한다.
부분일치를 허용하면 울산·경기 매물에 부산 생활인구가 붙는다.
`detectRegion`의 네 패턴은 전부 `^`로 시작한다.

**동명 시군구를 시군구명만으로 조회하지 않는다.**
`중구`는 서울·부산·대구·인천·대전·울산에 모두 있다. 지역화폐 조회에는 시도명을
함께 보내고, 응답의 시도·시군구가 요청과 다르면 값을 버린다(`matchesRequestedRegion`).
시도를 특정할 수 없는 주소는 외부 API를 호출조차 하지 않는다.

**결측을 0으로 만들지 않는다.**
금액·건수 필드가 비어 있을 때 0을 쓰면 사용자가 `결제금액 0원`이라는 거짓을 본다.
`toNullableNumber`로 null을 유지하고, null인 항목은 행 자체를 렌더하지 않는다.

**구간을 반올림해 접지 않는다.**
만원 단위 반올림은 서로 다른 구간을 같은 문자열로 만든다. 소수 첫째 자리까지
유지해 구간임이 사라지지 않게 한다.

**수집기가 없는 레이어는 `미수집`이 아니라 `연결 예정`이다.**
`미수집`은 곧 채워질 것이라는 기대를 만든다. 실제로는 구현 계획 단계다.

**같은 지표를 한 화면에서 두 번 말하지 않는다.**
거주인구·시설 밀집도·점포 구성은 화면의 다른 영역이 이미 담당한다(`delivery: 'other_panel'`).
이 패널에서 렌더하면 같은 지표가 `있음`과 `미수집`으로 동시에 보인다.

**상권까지의 거리를 반드시 표시한다.**
서울 공식 장소는 최대 5km 간격이다. 거리 없이 `지금 이 상권`이라고 하면
다른 생활권 지표를 자기 동네로 읽는다.

**서울 API는 https로만 호출한다.** 인증키가 경로 세그먼트에 실리므로 평문 http는 키 노출이다.

**API 오류 원문을 사용자에게 반환하지 않는다.** Postgres/RLS 메시지와 요청 URL은
서버 로그로만 보낸다.

## 서울 장소 좌표를 구한 방법

서울 실시간 API는 **좌표로 조회할 수 없다.** 장소명 또는 장소코드로만 조회된다.
따라서 매물 좌표에서 가장 가까운 공식 장소를 찾아 조회 파라미터로 쓴다.

좌표 원천은 데이터셋 페이지의 공식 첨부 `서울시 주요 121장소 영역.zip`이다.
ESRI shapefile(WGS84, `.prj`로 확인)의 폴리곤에서 면적가중 중심점을 계산했다.
121곳 전부 `coord_source: "official"`이며 추정한 좌표는 없다.
그중 82곳이 상권현황 데이터를 제공한다 (`has_commercial: true`).

데이터: `src/lib/data/seoul-hotspots.json`
조회: `src/lib/seoul-hotspots.ts` — `findNearestSeoulHotspot(lat, lng, radiusM = 3000)`
기본 3km를 넘으면 `null`을 반환한다. 그보다 멀면 매물 주변 상권이라 부를 수 없다.

## 채택하지 않은 것과 그 이유

**오픈업 (핀다)** — 전국 무료지만 약관 용어가 `AI 생성 정보`다. 공식적으로
"어떠한 사실도 증명하지 않으며 사실 증명에 활용할 수 없음"이라고 명시하고,
현금·지역화폐·온라인 플랫폼 반영 비중이 낮다고 스스로 밝힌다. 약관 제7조 제3항이
본인 상권분석 외 용도와 제3자 제공을 금지하고, 제8조가 복제·재판매를 금지한다.
→ SaaS 연동 불가.

**소상공인365** — 화면 조회와 PDF만 제공되고 기계판독 운영 API가 없다.
게다가 라이선스 문구가 상충한다. 기준 데이터 페이지는 "상업적 목적이 아닌
개인적 용도로만", 저작권정책은 출처표시 자유이용이다.
→ 상업 투입 전 서면 확인 필요. 운영 스크래핑은 채택하지 않는다.

**신한카드 데이터바다** — 시군구·읍면동 월별이지만 `시장추정매출(SAA_ADJST)`,
즉 신한 점유율을 보정한 추정치다. B2B 유료 계약 + IP 화이트리스트 필요.

**BC카드 빅데이터플랫폼** — 절대 매출액이 아니라 지수·비율 중심이다.
과거 OPEN API 목록 URL은 현재 HTTP 500이고 메뉴에서 사라졌다.

**삼성카드 상권분석** — 자체 데이터가 아니라 나이스지니데이타 제휴 리포트 판매다.
API 없음.

**나이스비즈맵 / NICE지니데이타** — 3사 중 유일하게 API·CSV 제공이 공식
명문화돼 있다. 다수 카드사 + POS 결합으로 실결제 집계와 추정이 분리된다.
프리미엄 보고서 55,000원/건. 전국 행정동 단위 매출이 필요하면 이 경로 또는
신한 데이터바다 유료 계약이 현실적인 유일한 길이다.

## 상태 표기 규칙

`describeLayerStatus()`가 유일한 문장 출처다. 컴포넌트에서 문장을 다시 만들지 않는다.

| 상태 | 사용자 문장 |
|---|---|
| `available` | 자료를 불러왔습니다. |
| `partial` | 일부 항목만 불러왔습니다. |
| `not_collected` | 아직 수집하지 않았습니다. |
| `unsupported` | 이 지역은 공개된 자료가 없습니다. |
| `unconfigured` | 관리자가 자료 연결을 준비하고 있습니다. |
| `failed` | 자료를 불러오지 못했습니다. |
| `empty` | 조회 범위에서 확인된 자료가 없습니다. |

API 키 부재는 `failed`가 아니라 `unconfigured`다. 예외를 던지지 않는다.
사용자에게 환경변수 이름을 노출하지 않는다.
