# 집포터 외부 매물 채널 연동 판정

확인일: 2026-10-11

## 판정 기준

- `API 직접등록`: 공개 문서와 인증키 발급 절차가 확인된 매물 등록 API
- `제휴 필요`: 서면 계약·승인 뒤 API·피드·파트너 포털 연동
- `파일 내보내기`: CSV·등록 시트·사진 ZIP 등 재입력 자료 제공
- `수동 보조`: 공식 등록화면 열기, 필드별 복사, 필수항목 점검 후 사용자가 최종 제출

## 결론

조사 대상인 네이버페이 부동산, 직방, 다방, 제주오일장신문, 교차로 계열 중 일반 개발자가 즉시 사용할 수 있는 공개 매물 등록 API는 확인되지 않았다. 비공개 B2B API나 피드의 부존재를 뜻하지는 않는다.

따라서 초기 제품은 `파일 내보내기 + 수동 보조`만 제공하고, 서면 제휴가 완료된 채널에 한해 `직접 발행 가능`으로 전환한다.

## 채널별 판정

### 네이버페이 부동산

- 판정: `제휴 필요`
- 공식 고객센터는 제휴 정보업체로부터 매물정보를 받아 노출하며 등록·수정은 해당 정보업체에 문의하도록 안내한다.
- 공개 NAVER Developers 목록에서 일반 중개사용 매물 등록 API는 확인되지 않았다.
- 제휴 전 제공 기능: 제휴 정보업체용 등록자료 내보내기, 문구 복사, 공식 경로 안내.
- 금지: 로그인 매크로, 비공개 엔드포인트 호출, 스크래핑, CAPTCHA 우회.

### 직방

- 판정: `제휴 필요`
- 일반 공인중개사는 중개사 사이트의 광고상품을 통해 등록·관리한다.
- 공개 개발자용 매물 등록 API는 확인되지 않았다.
- 공식 서비스 제휴 경로: `partnership@zigbang.com`
- 제휴 전 제공 기능: 등록자료 내보내기, 공식 등록화면 안내, 최종 제출 전 체크리스트.

### 다방

- 판정: `제휴 필요`
- 다방프로에서 공인중개사 회원이 지정 양식과 방법으로 매물을 등록한다.
- 공개 개발자용 매물 등록 API는 확인되지 않았다.
- 공식 사업제휴 경로: `biz@station3.co.kr`
- 제휴 전 제공 기능: 채널 규격 문구·사진 묶음과 수동 등록 보조.

### 제주오일장신문

- 판정: `제휴 필요`
- 회원용 등록·관리 화면은 있으나 공개 매물 등록 API는 확인되지 않았다.
- 공식 광고문의와 지역 고객센터를 통해 B2B 연동 여부를 확인해야 한다.
- 제휴 전 제공 기능: 오일장용 문구와 사진 묶음, 등록화면 안내.

### 교차로 계열

- 판정: 지역사별 `제휴 필요`
- 지역별 법인·도메인·상품·고객센터가 달라 한 곳의 승인이 전국 권한을 뜻하지 않는다.
- 지역사 계약에서 등록·수정·거래완료 처리와 네이버 재전송 권한을 별도로 확인한다.
- 제휴 전 제공 기능: 지역별 등록자료 내보내기와 수동 등록 보조.

## 제품 구현 원칙

- 한 번 입력한 공통 매물 사실에서 채널별 필수 필드와 문구를 만든다.
- 사진 파일명·순서·용량을 정리해 ZIP으로 내보낸다.
- 사용자가 공식 등록화면에서 최종 검수·제출한다.
- 등록·수정·거래완료 삭제까지 계약과 실제 테스트가 끝난 채널만 자동 전송을 켠다.
- 성공 여부를 검증하지 못한 동작은 성공으로 표시하지 않는다.
