# 집포터 2.0 제품·정보구조 명세

확정일: 2026-10-11

## 제품 한 문장

주소·사진·매물 특징을 한 번 입력하면 블로그 글과 카드뉴스를 만들고, 사람이 검토한 뒤 채널별로 허용된 방식의 발행 준비까지 끝내는 공인중개사용 도구.

## 첫 고객

매물 홍보를 직접 해야 하지만 글쓰기·디자인·채널별 반복 입력에 시간을 빼앗기는 소형 공인중개사무소.

## 핵심 흐름

1. 주소 입력 및 위치 확인
2. 사진 추가와 대표사진 선택
3. 생활 언어로 된 특징 칩 선택 및 직접 입력
4. 블로그·카드뉴스 동시 생성
5. 공통 사실과 채널별 표현 검토
6. 채널별 발행 준비
7. 사용자가 최종 확인 후 내보내기 또는 공식 연동 실행

## 채널 상태 모델

모든 채널은 다음 다섯 상태 중 하나만 표시한다.

- `직접 발행 가능`: 공식 API·피드·파트너 권한과 실제 성공 검증 완료
- `파일 다운로드`: 채널 규격에 맞는 사진·문서 묶음 제공
- `문구 복사`: 등록 화면에 붙여 넣을 필드별 문구 제공
- `연동 필요`: 사업제휴 또는 계정 권한이 있어야 활성화
- `지원 예정`: 조사·개발 전이며 동작을 약속하지 않음

공식 연동과 실제 성공 검증 전에는 `자동 등록`, `동시 발행`, `원클릭 등록`이라는 표현을 사용하지 않는다.

## 화면 구조

### 공개 랜딩

- 헤드라인: `매물 홍보물, 한 번 입력으로 끝`
- 설명: `주소·사진·특징만 넣으면 블로그 글과 카드뉴스를 만들고, 검토 후 채널별 발행 준비까지.`
- 주 행동: `내 매물로 시작하기`
- 첫 화면 아래에는 세 단계와 실제 결과 미리보기만 배치한다.
- 긴 기능 설명, 미확인 성과 수치, 연동되지 않은 플랫폼 로고 나열은 제거한다.

### 로그인 후 홈

- 가장 먼저 `새 매물 시작`을 표시한다.
- 다음 행동이 필요한 매물과 최근 결과만 보여준다.
- 기술 용어, 기능별 독립 메뉴, 관리자 정보는 기본 사용자 화면에서 숨긴다.

### 새 매물

- `주소 → 사진 → 특징` 세 단계만 기본 노출한다.
- 가격·면적·거래유형처럼 광고에 필요한 값은 주소 확인 후 필요한 시점에 묻는다.
- 고급 항목은 `더 추가하기`에 접어 둔다.

### 결과·발행 준비

- 블로그와 카드뉴스를 같은 화면의 탭으로 검토한다.
- 입력 원문, AI 제안, 사용자 수정 내용을 구분한다.
- 채널 카드에는 실제 가능한 동작과 필요한 추가 확인을 명확히 표시한다.

## 보안 책임 경계

### 웹

- 사용자·조직 인증, 매물·콘텐츠·작업 상태를 관리한다.
- 외부 플랫폼의 아이디·비밀번호·OTP·세션 쿠키를 받거나 저장하지 않는다.
- 로컬 에이전트에는 `설정됨/미설정` 상태만 요청한다.

### 로컬 에이전트

- 플랫폼 로그인정보 입력·암호화 저장·삭제를 담당한다.
- Electron main process에서 OS 사용자 계정에 묶인 `safeStorage`를 사용한다.
- renderer에는 복호화 API를 제공하지 않는다.
- 자동화 실행 직전에만 복호화하고 로그에 남기지 않는다.
- CAPTCHA와 2단계 인증은 우회하지 않고 사용자가 직접 완료한다.

## 의도적인 비범위

- 비공개 API 역공학
- CAPTCHA·기술적 보호조치 우회
- 매물·연락처 스크래핑
- 제휴 전 자동 로그인·DOM 매크로 등록
- 매출·문의·검색노출 보장
- 포털 수준의 매물 검색·시세·대출·뉴스 기능

## 단계별 출시

### P0 — 신뢰 회복

- 웹의 외부 플랫폼 비밀번호 입력·저장 경로 차단
- 저장소의 하드코딩된 키·계정 제거와 회전
- Electron 격리와 OS 암호화 저장
- 랜딩을 한 문장·한 행동 중심으로 단순화

### P1 — 발행 준비 MVP

- 채널별 필드 문구 생성
- 사진 순서·크기·파일명 정리와 ZIP 내보내기
- 블로그·카드뉴스 동시 검토
- 공식 등록화면 열기와 최종 확인 체크리스트

### P2 — 계약형 연동

- 제휴가 체결된 채널만 공식 API·피드 커넥터 추가
- 등록·수정·거래완료 삭제·재시도·중복 방지
- 채널별 성공 여부와 감사 이력

## 완료 기준

- 초보 사용자가 별도 설명 없이 주소·사진·특징 입력을 시작할 수 있다.
- 웹 요청·웹 DB·로그·HTML에 플랫폼 비밀번호가 나타나지 않는다.
- 채널별 지원 상태가 실제 연동 범위와 일치한다.
- 타입검사, 린트, 단위·브라우저 테스트, 프로덕션 빌드와 독립 보안·UX 리뷰를 통과한다.
