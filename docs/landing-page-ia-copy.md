# 집포터 공개 랜딩페이지 정보구조 및 한국어 카피

> 구현 상태: `src/app/page.tsx`에 반응형 공개 랜딩페이지로 반영됨. 네 가지 결과물 카드에는 가상 예시와 변동 가능성 고지를 함께 표시한다.

## 1. 전환 전략

### 핵심 방문자
- 디지털 도구에 익숙하지 않은 소규모 공인중개사
- 매물 홍보 글과 이미지를 직접 만들거나 외주를 맡기는 사람
- 기능의 수보다 “무엇을 넣으면 무엇이 나오는지”를 먼저 확인하려는 사람

### 페이지가 답해야 할 질문
1. 이 서비스는 내 어떤 일을 도와주는가?
2. 사용법이 어렵지는 않은가?
3. 내 매물로 어떤 결과를 만들 수 있는가?
4. 결과를 그대로 써도 되는가?
5. 어디서 시작하면 되는가?

### 핵심 전환 원칙
- 첫 화면에서 AI·자동화보다 **“매물 정보 한 번 입력 → 홍보 자료 여러 형태로 정리”**를 먼저 설명한다.
- 기능명만 나열하지 않고 **입력값과 결과물**을 함께 보여준다.
- “원클릭”, “완벽”, “즉시”, “매출 상승 보장” 같은 확인되지 않은 표현을 쓰지 않는다.
- 모든 주요 구간의 CTA 문구는 **“내 매물로 결과 받아보기”**로 통일한다.
- 로그인은 보조 동작으로 두고, 첫 방문자의 주 행동은 결과 확인으로 유도한다.

## 3-3. 문제 공감

**헤드라인**
> 매물은 준비됐는데, 홍보 자료를 만들 때마다 다시 시작하고 있나요?

**본문**
> 주변 환경을 찾아 정리하고, 블로그 문장을 쓰고, 카드뉴스 문구를 나누고, 짧은 영상 흐름까지 잡으려면 같은 매물 정보를 여러 번 옮기게 됩니다. 집포터는 매물 정보를 기준으로 필요한 내용을 연결해 정리합니다.

**문제 카드**

1. **주변 정보를 따로 찾는 번거로움**
   지도와 검색창을 오가며 매물 주변의 특징을 모아야 합니다.

2. **매번 새로 쓰는 홍보 문장**
   같은 매물도 블로그, 카드뉴스, 쇼츠에 맞게 다시 구성해야 합니다.

3. **흩어지는 사진과 초안**
   매물별 자료가 여러 폴더와 메모에 나뉘어 관리하기 어려워집니다.

## 3-5. 이용 방법

**헤드라인**
> 주소부터 넣고, 순서대로 따라가세요

**서브카피**
> 처음 사용하는 분도 현재 단계와 다음 할 일을 알 수 있도록 매물 단위로 진행합니다.

### 1. 매물 정보 입력
> 주소, 거래 유형, 가격, 면적과 매물의 특징을 입력합니다.

### 2. 사진 추가
> 홍보에 사용할 매물 사진과 동영상을 등록합니다.

### 3. 필요한 결과 선택
> 입지분석, 블로그, 카드뉴스, 쇼츠 중 지금 필요한 작업을 선택합니다.

### 4. 결과 확인 및 수정
> 생성된 내용을 확인하고 실제 매물과 중개사무소 기준에 맞게 고쳐 사용합니다.

**보조 안내**
> 모든 기능을 한 번에 사용할 필요는 없습니다. 필요한 결과물부터 시작할 수 있습니다.

## 3-6. 기능 상세

**헤드라인**

### 입지분석
**제목**
> 검색 자료를 상담 가능한 설명으로

**본문**
> 매물 주변의 생활·교통·교육·상권 관련 정보를 모아 확인하고, 매물의 입지 포인트를 설명할 때 참고할 수 있도록 정리합니다.

**보조 문구**
> 수집 가능한 정보와 분석 결과는 매물 위치 및 연동 데이터에 따라 달라질 수 있습니다.

### 블로그
**제목**
> 빈 화면에서 시작하지 않는 매물 소개 글

**본문**
> 입력한 매물 정보와 입지 내용을 바탕으로 제목, 매물 개요, 주요 장점, 주변 환경, 문의 안내가 포함된 글 초안을 만듭니다.

**보조 문구**
> 게시 전 가격, 면적, 주소 노출 범위와 표현을 직접 확인해 주세요.

### 카드뉴스
**제목**
> 긴 설명을 카드별 핵심 문구로

**본문**
> 매물의 대표 정보와 장점을 여러 장의 카드 흐름으로 구성합니다. 등록한 사진을 바탕으로 결과를 확인하고 수정할 수 있습니다.

**보조 문구**
> 사진의 수와 품질에 따라 결과 구성이 달라질 수 있습니다.

### 쇼츠
**제목**
> 무엇을 말할지부터 정리된 쇼츠 스크립트

**본문**
> 영상의 시작, 매물 소개, 핵심 장점, 마무리 안내를 장면별 스크립트로 구성합니다. 촬영이나 편집 전에 이야기 흐름을 잡는 데 활용할 수 있습니다.

**보조 문구**
> 현재 제공 범위가 스크립트 생성이라면 CTA나 기능명에서 “영상 자동 완성”으로 표현하지 않습니다.

## 3-8. 안심 안내

**헤드라인**
> AI가 초안을 만들고, 최종 판단은 중개사가 합니다

**본문**
> 생성된 분석과 콘텐츠는 업무를 돕기 위한 초안입니다. 게시하거나 고객에게 안내하기 전에 실제 매물 정보, 가격, 면적, 권리관계, 주변 정보와 광고 관련 표현을 확인해 주세요.

**체크 항목**
- 생성 결과를 화면에서 확인합니다.
- 실제 매물과 다른 표현은 수정합니다.
- 공개하면 안 되는 상세 주소와 개인정보를 점검합니다.
- 최종 게시 책임과 판단은 사용자에게 있습니다.

> 구현 메모: 개인정보 마스킹 기능이 실제 적용되는 범위를 확인하기 전에는 “개인정보를 자동으로 완벽히 보호합니다”라고 쓰지 않는다.

## 3-9. FAQ

### Q. 컴퓨터를 잘 다루지 못해도 사용할 수 있나요?
> 매물 주소와 기본 정보를 입력한 뒤, 필요한 결과물을 선택하는 순서로 구성되어 있습니다. 화면에 표시되는 단계에 따라 진행하면 됩니다.

### Q. 무엇을 입력해야 하나요?
> 주소를 기본으로 거래 유형, 가격, 면적, 사진과 매물의 특징을 입력할 수 있습니다. 입력 내용이 구체적일수록 실제 매물에 맞게 결과를 확인하고 다듬기 쉽습니다.

### Q. 입지분석에서는 무엇을 볼 수 있나요?
> 매물 주변의 시설과 생활·교통·교육·상권 관련 정보를 바탕으로 정리된 내용을 확인할 수 있습니다. 제공 범위는 매물 위치와 연동 데이터에 따라 달라질 수 있습니다.

### Q. 만들어진 글과 이미지를 바로 올려도 되나요?
> 생성 결과는 초안으로 확인해 주세요. 게시 전 실제 매물 정보, 가격, 면적, 주소 노출 범위, 사진 사용 권한과 광고 표현을 직접 검토하고 필요한 부분을 수정해야 합니다.

### Q. 쇼츠 영상도 완성되나요?
> 현재 제품이 장면별 스크립트 생성까지만 제공한다면, 영상 파일이 자동 완성되는 것으로 안내하지 않습니다. 실제 제공 범위에 맞춰 “쇼츠 스크립트”로 표시합니다.

### Q. 요금과 이용 조건은 어떻게 확인하나요?
> 확정된 요금제와 이용 조건이 있다면 별도 요금 안내에서 확인할 수 있도록 연결합니다. 확정 전에는 무료 체험 기간, 무료 제공량 또는 자동 결제 조건을 표시하지 않습니다.

### Q. 기존 계정이 있습니다.
> 상단의 ‘로그인’을 눌러 이용할 수 있습니다.

## 4. CTA 및 폼 마이크로카피

### CTA 일관성
- 기본 CTA: **내 매물로 결과 받아보기**
- 로그인 링크: **로그인**
- 회원가입 화면 제목: **계정 만들기**
- 첫 입력 화면 제목: **어떤 매물의 결과를 받아볼까요?**

### 첫 입력 화면 예시
**주소 필드 라벨**
> 매물 주소

**주소 플레이스홀더**
> 도로명 또는 지번 주소를 입력하세요

**매물 특징 라벨**
> 꼭 알리고 싶은 장점

**매물 특징 도움말**
> 예: 역과 가까움, 주차 가능, 남향, 공원 인접

**다음 버튼**
> 사진 추가하기

**결과 선택 제목**
> 어떤 결과가 필요한가요?

**선택지**
- 입지분석
- 블로그 글
- 카드뉴스
- 쇼츠 스크립트

## 5. 권장 화면 배치

### 데스크톱
- 히어로 왼쪽: 헤드라인, 설명, CTA
- 히어로 오른쪽: 매물 정보가 네 가지 결과물로 이어지는 실제 UI 미리보기
- 기능 섹션: 설명과 실제 결과 화면을 번갈아 배치
- FAQ 아래: 최종 CTA를 넓은 단일 패널로 배치

### 모바일
- 헤드라인은 3~4줄 이내
- 결과물 칩 네 개를 첫 화면 안에 노출
- 기능 카드는 한 열로 배치
- 하단 고정 CTA: **내 매물로 결과 받아보기**
- 고정 CTA가 푸터나 입력 요소를 가리지 않도록 하단 여백 확보

## 6. 게시 전 사실 확인 체크리스트

아래 항목은 제품에서 실제 동작하는 경우에만 랜딩페이지에 노출한다.

- 카드뉴스가 이미지 파일로 생성·다운로드되는지
- 쇼츠가 스크립트만 제공되는지, 영상 파일까지 생성되는지
- 블로그 또는 SNS 자동 업로드가 현재 사용 가능한지
- 입지분석에 실제 표시되는 데이터 항목과 제공 지역
- 생성 결과의 수정·저장·다운로드 범위
- 요금제, 결제 시점, 무료 제공량 및 체험 조건
- 고객 수, 생성 건수, 후기와 고객 로고의 사용 허가
- 지원 채널과 응답 가능 시간

확인 전에는 수치, 후기, “무료”, “무제한”, “즉시”, “완벽”, “매출 증가” 표현을 사용하지 않는다.
