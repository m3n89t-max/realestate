# 집포터 공개 웹 UX 벤치마크

**확인일:** 2026-10-11 (KST)  
**범위:** 로그인 없이 접근 가능한 공식 웹·도움말·공식 앱 스토어 설명. Zillow·Redfin·Canva는 자동화 브라우저에서 차단되어 공식 검색 노출문구/도움말을 교차 확인했고, Realtor.com은 공식 웹 본문 대신 공식 앱 스토어 설명을 보조 근거로 썼다. 따라서 화면 픽셀 단위 복제가 아니라 공개적으로 확인되는 정보구조·문구·흐름을 비교했다.

## 한 줄 결론

집포터는 **“주소·사진·특징을 한 번 입력 → 블로그와 카드뉴스를 동시에 생성 → 사람이 검토 → 채널별 발행 준비 상태로 넘김”**만 첫 화면에서 보여줘야 한다. 경쟁사의 지도·시세·검색 기능을 따라가기보다, 피터팬의 짧은 등록 약속, Canva의 템플릿 기반 다중 결과물·검토 흐름, 직방의 채널별 노출 조건 고지를 결합하는 편이 맞다.[5][8][23]

## 서비스별 관찰과 적용 판단

### 1) 네이버페이 부동산

- **공개 UX:** 첫 진입의 중심은 “단지, 주소, 지하철, 초등학교 검색” 한 칸이다. 홈·관심부동산·분양·뉴스·우리집·대출 등 목적별 내비게이션과 아파트 매물 동향을 함께 둔다.[1] 지도 화면은 매물·단지·학군·주변 정보를 한곳에서 찾는 구조다.[2]
- **신뢰:** 고객센터는 확인매물 아이콘, 관심매물/관심지역, 매물알림, 중개사 프로필, 허위매물 신고/처리를 별도 도움말로 분리한다.[3]
- **차용:** 첫 입력을 **주소 검색 하나**로 시작하고, 주소 선택 뒤에만 사진·특징을 노출한다. 진행 중에는 `입력 → 생성 → 검토 → 발행 준비` 네 단계만 고정 표시한다.
- **버림:** 시세 그래프, 뉴스, 대출, 복수 메뉴처럼 탐색 목적의 기능을 랜딩에 섞지 않는다. 집포터는 매물 검색 포털이 아니라 제작 도구다.

### 2) 직방

- **공개 UX:** 소비자 화면은 아파트·빌라/투룸·원룸·오피스텔·상가/사무실·단기임대를 상단에서 바로 나누고, 검색창은 아파트·지역·역·학교를 받는다.[4] 중개사 상품 페이지는 광고 등록에 필요한 상품, 노출 개수, 추천 라벨, 가격과 조건을 명시하며, 파트너사 동시 노출은 “될 수 있습니다”라고 조건부로 표현한다.[5]
- **신뢰:** `허위광고 OUT`, `안심운영정책`, `안심 추천 매물` 등 운영정책과 라벨을 구매 기능 옆에 둔다.[5]
- **차용:** 결과 화면에서 `블로그 글`, `카드뉴스`를 탭으로 나누고 각 채널에 **준비됨 / 추가 확인 필요 / 내보내기 가능** 상태를 붙인다. 외부 채널 연동이 확인된 경우에만 채널명과 동작을 구체적으로 표시한다.
- **버림:** 상품·가격·노출 우선순위를 첫 화면에 쌓거나, 확인되지 않은 채널에 “자동 등록·동시 노출”을 약속하지 않는다. 조건부 문구를 작은 각주로 숨기지도 않는다.

### 3) 다방

- **공개 UX:** 다방프로 고객센터는 `회원/계정`, `매물/광고`, `상품/결제`로 질문을 먼저 분류하고 검색을 제공한다.[6] 공식 이용설명서는 매물 정보를 위치·기본정보·추가정보·상세설명·사진 업로드로 나누며, 이는 단계형 입력의 전형을 보여준다. 다만 이 문서는 2016년 자료이므로 현재 화면 사양의 근거로는 쓰지 않았다.[35]
- **차용:** 입력 필드는 한 화면의 긴 폼 대신 `주소 → 사진 → 특징` 세 덩어리로 나눈다. 질문은 예시 선택칩으로 답하게 하고 상세설명은 AI 초안 뒤에 선택 수정으로 돌린다.
- **버림:** 계정·광고상품·결제를 제작 시작 전에 요구하지 않는다. 오래된 매물등록 폼처럼 모든 세부값을 선입력시키지 않는다.

### 4) 피터팬의 좋은방 구하기

- **공개 UX:** 첫 화면에서 `#수수료 0원`, `좋은방 구할땐 피터팬`, `APP 다운로드`를 짧게 제시한다. 방 내놓기 영역은 `4개 채널 동시노출`, `5분 간편 등록`, `빠르게 방 내놓기`처럼 혜택·시간·행동을 한 묶음으로 보여준다.[8]
- **검색/신뢰:** 회사 소개 페이지는 THE 클린매물·N확인 매물을 신뢰 장치로 제시하고, 주차·반려동물·엘리베이터 같은 생활 언어 필터를 제공한다고 설명한다.[9]
- **차용:** 집포터도 첫 화면을 `매물 홍보물, 한 번 입력으로 끝` + `무료로 만들어보기`로 압축한다. 예상 소요시간과 필요한 준비물(`주소·사진 3장 이상`)을 CTA 바로 아래 표시한다. 특징 입력은 `역세권`, `채광`, `반려동물`, `주차` 같은 칩으로 제공한다.
- **버림:** 공식 연동 범위가 확인되지 않은 상태에서 피터팬식 `N개 채널 동시노출`을 복제하지 않는다. 집포터는 `채널별 발행 준비`라고 말하고 실제 연결 여부를 상태로 구분한다.

### 5) 디스코

- **공개 UX:** 지도가 기본 배경이며, `건물명·지번·도로명 검색`, `필터`, `매물 탐색`, 실거래가, 지역 전문가, 추천 매물을 같은 화면에 배치한다.[10]
- **차용:** 주소 자동완성과 주소 후보 확인, 지번/도로명 모두 허용하는 입력은 가져온다. 선택된 주소는 지도 미니 프리뷰로 재확인시킨다.
- **버림:** 지도 위 다수 레이어·마커·전문가·추천·게시물을 동시에 보여주는 고밀도 구조는 버린다. 제작 맥락에서는 지도는 주소 확인용 보조요소일 뿐이다.

### 6) 알스퀘어

- **공개 UX:** 첫 화면은 `따져봐야 할 모든 조건에 딱 맞는 최적의 사무실`과 `상담 신청하기`로 가치와 다음 행동을 붙인다. 이후 DB 규모, 전국 범위, 만족도, 임대차·인테리어·가구까지 한 번에 해결한다는 근거와 고객 사례를 제시한다.[12]
- **차용:** 결과물 종류가 아니라 **완료되는 일**을 앞세운다. 예: `매물 소개글과 카드뉴스를 만들고, 검토 후 채널별 발행 준비까지`.
- **버림:** 긴 회사 소개, 대형 수치, 사례 로고를 첫 화면에 올리지 않는다. 초기 집포터는 검증 가능한 수치만 쓰고, 신뢰는 샘플 결과·입력 보안·수정 가능 여부로 만든다.

### 7) Zillow

- **공개 UX:** 홈은 매물 검색, Zestimate 주택가치 비교, 지역 전문가 연결을 한 검색 진입점에 묶는다.[13] 고급 검색은 가격·침실·주택유형 등 기본 필터에 키워드 필터를 더하고, 즐겨찾기·공유 행동을 추천 개선에 활용한다고 설명한다.[14] 매도 화면은 중개인, 현금 제안, 전통 매도, FSBO 등 선택지를 먼저 비교하게 한다.[15]
- **모바일:** 저장 검색의 즉시/일일 알림과 신규 매물 알림을 제공한다.[34]
- **차용:** 처음에는 필수값만 받고, `고급 특징 추가`는 접어둔다. 목표가 다른 사용자는 시작점에서 `블로그 중심 / 카드뉴스 중심 / 둘 다`만 고르게 한다.
- **버림:** 가치평가·대출·전문가 연결·추천 개인화처럼 집포터 핵심 작업 밖의 가지를 붙이지 않는다. 알림도 결과 생성 완료나 검토 필요처럼 작업 상태에만 쓴다.

### 8) Redfin

- **공개 UX:** 검색은 동네·도시·우편번호·MLS 번호·지도 직접 그리기 등 여러 진입 방식을 지원한다.[17] 모바일은 자연어로 원하는 집을 설명하고, 필터 적용 후 검색 저장·공동 구매자와 즐겨찾기 공유까지 이어진다.[29] 공식 데이터 품질 페이지는 MLS 피드 신규 매물의 게시 속도를 수치로 설명해 최신성을 신뢰요소로 사용한다.[28]
- **등록/광고:** FSBO는 별도 등록 유형으로 구분되고 검색 필터에서도 `By owner`로 찾게 한다.[18]
- **차용:** 생성 후 `검토 링크 공유`, 댓글/승인, 수정 이력을 둔다. 신뢰 문구는 추상적 “AI가 알아서”가 아니라 `원문 입력 유지`, `수정 가능`, `채널별 글자수·이미지 규격 점검`처럼 검증 가능한 상태로 표현한다.
- **버림:** 자연어 자유입력을 첫 단계의 유일한 방식으로 쓰지 않는다. 초보자는 빈 프롬프트보다 주소·사진·특징이라는 구조화된 가이드가 더 안전하다.

### 9) Realtor.com

- **공개 UX:** 공식 앱 설명은 가격·크기·침실/욕실·학교·통근시간 필터, 지도 영역 직접 그리기, 주변 편의시설·소음·홍수위험 레이어를 안내한다.[26][27]
- **차용:** 전문가용 용어보다 사용자 상황 언어를 쓴다. 특징 칩은 `사진에서 잘 보이는 장점`, `생활 편의`, `교통`, `관리 상태`처럼 묶고 각 묶음에 예시를 둔다.
- **버림:** 많은 필터와 위험 레이어를 제작 시작 화면에 복제하지 않는다. 입력값이 부족할 때만 관련 질문 하나를 추가하는 점진적 온보딩이 적합하다.

### 10) Canva — 콘텐츠 제작 흐름

- **공개 UX:** Canva는 빈 캔버스보다 전문 템플릿을 고르고 커스터마이즈하는 진입을 강조한다.[30]
- 템플릿에는 업로드 파일·브랜드 자산·연결 앱 콘텐츠를 넣을 수 있고, 공유 버튼에서 템플릿 링크·다운로드 등 다음 행동을 모은다.[23][24][31]
- 공식 도움말은 앱별로 지원 형식·다중 페이지·예약 게시 가능 여부가 다르다고 명시한다.[32]
- **차용:** 주소·사진·특징 입력 뒤 즉시 `블로그 미리보기`와 `카드뉴스 미리보기`를 만든다. 사용자는 템플릿 선택 → 내용 검토 → 채널별 내보내기/복사의 단순 흐름만 본다. 한 곳의 `발행 준비` 버튼을 누르면 채널별 가능한 동작을 보여준다.
- **버림:** Canva식 범용 편집기 전체를 만들지 않는다. 드래그앤드롭·무한 템플릿·복잡한 툴바 대신 사진 순서, 제목, 핵심 특징, 톤 정도만 수정하게 한다. 앱마다 지원 범위가 다른데도 하나의 `자동 발행` 버튼으로 뭉개지 않는다.[32]

## 6개 UX 축별 집포터 설계안

| 축 | 차용할 패턴 | 버릴 패턴 | 집포터 권장 구현 |
|---|---|---|---|
| **첫 화면** | 네이버의 단일 검색창, 피터팬의 혜택+시간+CTA, 알스퀘어의 결과 중심 문장 | 기능 4종 나열, 지도·시세·뉴스 동시 노출, 긴 사용법 | 헤드라인 `매물 홍보물, 한 번 입력으로 끝`; 서브 `주소·사진·특징만 넣으면 블로그와 카드뉴스를 만들고 채널별 발행 준비까지`; CTA `무료로 만들어보기`; 아래에 `약 3분 · 가입 없이 미리보기`(실제 정책이 맞을 때만) |
| **매물 등록/광고** | 다방의 단계형 필드, 피터팬의 소요시간, 직방의 노출 조건 명시 | 모든 상세정보 선입력, 유료상품 선노출, 미확인 채널 자동등록 약속 | `1 주소 2 사진 3 특징` 3단계; 자동 저장; 주소로 기본정보 제안 후 사용자 확인; 외부 전송은 채널별 권한·연동 상태를 명시 |
| **검색/필터** | 네이버·디스코의 주소 자동완성, 피터팬의 생활 언어 칩, Zillow의 고급필터 접기 | 포털 수준의 수십 개 필터, 지도 레이어, 업계 용어 | 검색은 주소 확인에만 사용; 특징은 6~10개 추천칩+직접입력; 고급 옵션은 `더 추가하기`에 숨김 |
| **신뢰요소** | 네이버/피터팬의 확인 라벨, Redfin의 구체적 데이터 품질, 직방의 정책 링크 | 근거 없는 No.1·정확도·성과 수치, 애매한 `AI 자동` | `입력 원문`, `AI 제안`, `사용자 수정`, `채널 규격 확인`을 시각적으로 구분; 사진/주소의 저장·삭제 정책과 전송 전 최종 확인을 CTA 근처에 표시 |
| **모바일 CTA** | 피터팬의 반복되는 단일 CTA, Canva의 Share 허브, Zillow/Redfin의 저장·공유 | 여러 색 CTA, 하단을 가리는 배너, 즉시 앱 설치 강요 | 하단 고정 CTA는 단계마다 하나: `주소 확인`→`사진 추가`→`초안 만들기`→`검토 완료`→`발행 준비`; 보조 행동은 텍스트 링크 |

## 권장 핵심 플로우

1. **주소 입력:** 자동완성 → 선택 주소와 미니 지도 확인.
2. **사진 추가:** 대표사진 자동 제안, 순서만 바꾸게 함.
3. **특징 선택:** 생활 언어 칩 6~10개 + 직접입력 1칸.
4. **동시 생성:** 블로그 초안과 카드뉴스를 병렬 생성.
5. **한 화면 검토:** 공통 사실은 한 번 수정하면 양쪽에 반영; 채널별 표현만 별도 조정.
6. **발행 준비:** 각 채널 카드에 `직접 발행 가능`, `파일 다운로드`, `문구 복사`, `연동 필요`, `지원 예정` 중 실제 상태를 표시.
7. **최종 확인:** 사용자가 체크한 뒤에만 외부 동작. 공식 연동·권한이 검증되기 전에는 버튼과 문구 모두 `자동 등록`을 사용하지 않음.

## 바로 쓸 수 있는 카피

- **헤드라인:** `매물 홍보물, 한 번 입력으로 끝`
- **설명:** `주소·사진·특징만 넣으면 블로그 글과 카드뉴스를 만들고, 검토 후 채널별 발행 준비까지.`
- **주 CTA:** `무료로 만들어보기`
- **입력 도우미:** `주소를 먼저 알려주세요` → `사진을 올려주세요` → `이 매물의 장점을 골라주세요`
- **생성 완료:** `두 가지 홍보물이 준비됐어요`
- **발행 영역:** `어디에 어떻게 내보낼까요?`
- **연동 미확인 채널:** `문구 복사·이미지 다운로드` / `직접 게시 필요`
- **금지 카피:** `모든 채널 자동 등록`, `한 번에 자동 발행`, `네이버·직방 동시 등록` — 공식 연동과 실제 성공 검증 전에는 사용 금지.

## 우선순위

- **P0:** 랜딩을 결과 중심 1문장+1 CTA로 축소, 3단계 입력, 두 결과물 동시 미리보기, 채널별 상태 라벨.
- **P1:** 공통 사실 일괄 수정, 모바일 하단 단일 CTA, 검토 링크 공유, 입력/AI/사용자 수정 표시.
- **P2:** 채널 규격 검사, 승인 이력, 검증된 공식 연동만 선택적으로 추가.
